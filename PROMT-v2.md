Важно сохранить баланс:

образность и визуальную запоминаемость;

уважительное отношение к теме психического здоровья;

на тесте — в помощь;

на странице “о проекте” — обратно в основные разделы.

14. Что особенно усилить по сравнению с текущей версией
    При разработке нового варианта сайта не ограничивайся имеющейся базовой структурой, а обязательно усили:

Масштаб

добавь отдельные страницы для конкретных состояний;

сделай сайт многоуровневым, но понятным.

Подразделы

добавь внутренние секции, якоря, блоки “похожие состояния”, “что поможет”, “куда дальше”.

Кликабельность

карточки должны вести на страницы;

меню должно быть живым;

кнопки должны быть распределены по логике пользовательского пути.

Информативность

каждая страница должна раскрывать отдельную задачу;

не оставлять страницы “пустыми” по смыслу.

Помощь

help-блок должен появляться не только внизу;

на главной, в каталоге и на страницах состояний должен быть свой путь к помощи.

Визуальную выразительность

убрать ощущение одинаковых белых блоков;

создать иерархию секций;

усилить контраст важного.

Точность

все заголовки, подписи и кнопки должны быть однозначными;

без расплывчатых смыслов.

    В результате нужен сайт, который:

выглядит как завершённый продукт;

имеет понятную древовидную структуру;

содержит не только общие страницы, но и внутренние страницы по темам;

даёт пользователю ясный путь от знакомства с темой к обращению за помощью;

включает живой контент;

визуально выделяет важные разделы;

не выглядит как простой учебный макет.

16. Дополнительное требование к качеству
    Перед финальной сдачей проверь:

есть ли у каждой страницы своя функция;

нет ли пустых однотипных экранов;

понятен ли следующий шаг пользователю;

достаточно ли заметен блок помощи;

есть ли живой контент;

есть ли отдельные внутренние страницы;

различаются ли страницы по назначению;

не выглядит ли сайт “серой массой”;

есть ли чёткая логика переходов;

можно ли понять идею сайта без объяснений.
